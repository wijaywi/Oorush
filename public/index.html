Oorush blockchain

Build for a post-quantum future.

Oorush is an educational Dilithium5-signed UTXO blockchain MVP with encrypted wallets and a small proof-of-authority node.

Explore Oorush Explore features

Post-quantum signatures

Transactions and blocks use Dilithium5 signatures for the educational local network.

Encrypted wallets

Wallet files use Argon2id and AES-256-GCM. Private keys are never exported by default.

Local-first node

The TCP node stays loopback-only by default and persists validated chain state safely.

Oorush is experimental software. Do not use it for real funds.
